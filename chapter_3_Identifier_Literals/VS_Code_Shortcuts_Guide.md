# VS Code Keyboard Shortcuts Reference

This folder contains a comprehensive collection of **Visual Studio Code (VS Code) default keyboard shortcuts** for both **macOS** and **Windows/Linux** users. All shortcuts are organized in clean, easy-to-read Markdown tables by category.

## Shortcut Categories

Each file organizes shortcuts into the following sections:

| Category | Description |
| :--- | :--- |
| **General** | Command Palette, Quick Open, Settings, and Window management |
| **Basic Editing** | Cut, copy, paste, delete lines, comments, and indentation |
| **Navigation** | Go to symbols, lines, problems, and navigate editor history |
| **Search and Replace** | Find, replace, and search across files |
| **Multi-cursor and Selection** | Multiple cursors, expanding selections, and bulk edits |
| **Rich Languages Editing** | IntelliSense, formatting, definitions, refactoring |
| **Editor Management** | Split editors, switch tabs, and manage editor groups |
| **File Management** | Create, open, save, and close files |
| **Display** | Toggle panels, sidebars, zoom, and full screen |
| **Debug** | Breakpoints, step into/over, and debugging controls |
| **Integrated Terminal** | Open terminal, scroll, and copy/paste in terminal |

## How to Use

1. Open the file for your operating system:
   - **Mac users** → `VS_Code_KeyBoard_Mac_Short_cuts.md`
   - **Windows/Linux users** → `VS_Code_KeyBoard_Windows_Short_cuts.md`

2. Browse by category or use `Ctrl + F` (Windows/Linux) / `Cmd + F` (Mac) to search for a specific shortcut.

3. Click on any file link above to jump directly to the shortcut reference.

---

## Customizing Shortcuts

You can customize any shortcut in VS Code by opening the Keyboard Shortcuts editor:

| OS | Shortcut |
| :--- | :--- |
| Windows / Linux | `Ctrl + K` `Ctrl + S` |
| macOS | `Cmd + K` `Cmd + S` |

Or navigate via menu:
- **Windows/Linux**: `File > Preferences > Keyboard Shortcuts`
- **macOS**: `Code > Preferences > Keyboard Shortcuts`
