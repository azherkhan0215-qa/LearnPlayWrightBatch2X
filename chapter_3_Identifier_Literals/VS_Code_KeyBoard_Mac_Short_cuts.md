# VS Code Keyboard Shortcuts for Mac

A comprehensive reference of essential Visual Studio Code keyboard shortcuts for macOS users.

---

## General

| Shortcut                  | Action                      |
| :------------------------ | :-------------------------- |
| `Cmd + Shift + P`         | Show Command Palette        |
| `Cmd + P`                 | Quick Open (Go to File)     |
| `Cmd + Shift + N`         | New Window                  |
| `Cmd + W`                 | Close Window / Editor       |
| `Cmd + ,`                 | Open User Settings          |
| `Cmd + K Cmd + S`         | Open Keyboard Shortcuts     |

---

## Basic Editing

| Shortcut                                      | Action                           |
| :-------------------------------------------- | :------------------------------- |
| `Cmd + X`                                     | Cut line (empty selection)       |
| `Cmd + C`                                     | Copy line (empty selection)      |
| `Cmd + Shift + K`                             | Delete line                      |
| `Cmd + Enter`                                 | Insert line below                |
| `Cmd + Shift + Enter`                         | Insert line above                |
| `Cmd + Shift + \`                             | Jump to matching bracket         |
| `Cmd + ]` / `Cmd + [`                         | Indent / Outdent line            |
| `Home` / `End`                                | Go to beginning / end of line    |
| `Cmd + Up` / `Cmd + Down`                     | Go to beginning / end of file    |
| `Option + Up` / `Option + Down`               | Move line up / down              |
| `Option + Shift + Up` / `Option + Shift + Down`| Copy line up / down             |
| `Cmd + /`                                     | Toggle line comment              |
| `Shift + Option + A`                          | Toggle block comment             |
| `Cmd + K Cmd + C`                             | Add line comment                 |
| `Cmd + K Cmd + U`                             | Remove line comment              |
| `Option + Z`                                  | Toggle word wrap                 |
